## About the Workshop

### :point_right: [Program Website](https://alleninstitute.org/events/educator-coding-workshop-2026)

### Learning Outcomes
#### Participants will be able to:  
1. Learn the basics of Python programming
2. Identify and learn to use resources for coding with Python
3. Use Python to analyze open neuroscience data through an already developed lesson plan
4. Explore generative AI tools and identify possible use cases for them along with necessary guardrails
5. Learn best practices in coding pedagogy for their classrooms
6. Discuss how they would integrate coding with Allen Institute data in their class(es)
